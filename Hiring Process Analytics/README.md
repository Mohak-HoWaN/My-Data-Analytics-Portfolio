# Hiring Process Analytics

## 📌 Project Overview
This project delves into human resources data to uncover macro insights related to job market trends and departmental performance metrics within the hiring pipeline. It aims to streamline the recruitment process by identifying key areas of improvement.

## 🎯 Objectives
- Analyze historical hiring data to identify trends in candidate sourcing and conversion rates.
- Evaluate departmental performance metrics.
- Provide recommendations to optimize the recruitment funnel.

## 🛠️ Tools & Technologies
- **Data Analysis:** Python, Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn, Tableau/PowerBI (if applicable)
- **Reporting:** Microsoft Excel, PowerPoint

## 📊 Methodology
1. **Data Cleaning:** Handled missing values and standardized data formats across different departments.
2. **Exploratory Data Analysis (EDA):** Visualized hiring trends over time, source efficiency, and departmental growth.
3. **Statistical Analysis:** Applied statistical methods to evaluate the significance of hiring metrics.
4. **KPI Tracking:** Established KPIs to monitor the health of the hiring process.

## 🚀 Results & Impact
- Identified the most efficient candidate sourcing channels.
- Highlighted departments with the longest time-to-hire and proposed specific interventions.
- Created a comprehensive reporting structure for ongoing HR analytics.
