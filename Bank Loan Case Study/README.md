# Bank Loan Default Risk Case Study

## 📌 Project Overview
Mitigating risk is a primary concern for financial institutions. This case study focuses on identifying behavioral and financial patterns indicative of a client's likelihood to default on loan installments using exploratory data analysis.

## 🎯 Objectives
- Analyze applicant data to identify factors correlated with loan defaults.
- Segment customers based on their risk profiles.
- Provide data-driven recommendations to the risk assessment team to minimize financial loss.

## 🛠️ Tools & Technologies
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebooks
- **Techniques:** Risk Analytics, Handling Large Datasets, Outlier Detection

## 📊 Methodology
1. **Data Preprocessing:** Cleaned a large-scale financial dataset, handling missing values and scaling features.
2. **Exploratory Data Analysis (EDA):** Conducted univariate and bivariate analysis to understand the distribution of variables like income, loan amount, and credit history.
3. **Risk Profiling:** Segmented the data to compare the profiles of defaulters versus non-defaulters.
4. **Correlation Analysis:** Identified the strongest predictors of default risk.

## 🚀 Results & Impact
- Highlighted key high-risk customer profiles based on income-to-loan ratios and credit history.
- Developed a comprehensive Jupyter Notebook detailing the end-to-end analytical process.
- Provided actionable guidelines for adjusting loan approval thresholds.
