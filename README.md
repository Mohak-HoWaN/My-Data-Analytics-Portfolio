### 1. Data Analytics Process

### [2. Instagram User Analytics](./Instagram%20User%20Analytics.pptx)
> **Objective:** Analyzed Instagram user engagement metrics to discover audience behaviors and optimize content strategy.
* **Core Skills:** Social Media Analytics, Engagement Tracking, KPI Reporting.
* **Key Deliverables:** Strategic presentation summarizing user trends.

### [3. Operation & Metric Analytics](./Operation%20Analytics)
> **Objective:** Evaluated key operational metrics to identify bottlenecks and optimize internal processes.
* **Core Skills:** Process Optimization, Metric Tracking, Root Cause Analysis.

### [4. Hiring Process Analytics](./Hiring%20Process%20Analytics)
> **Objective:** Uncovered macro insights related to job market trends and departmental performance metrics within the hiring pipeline.
* **Core Skills:** Statistical Analysis, KPI Tracking, Performance Reporting.

### [5. IMDb Movie Analytics](./IMDB%20Movie%20Analytics)
> **Objective:** Analyzed extensive IMDb datasets to identify critical trends driving movie success, audience ratings, and studio profitability.
* **Core Skills:** Data Cleaning, Trend Analysis, Advanced Excel, Executive Presentation.
* **Key Deliverables:** Comprehensive video presentation and a detailed PowerPoint deck summarizing strategic findings.

### [6. Bank Loan Case Study](./Bank%20Loan%20Case%20Study)
> **Objective:** Identified behavioral and financial patterns indicative of a client's likelihood to default on loan installments.
* **Core Skills:** Risk Analytics, Pandas, Jupyter Notebooks, Large-Scale Data Handling.
* **Key Deliverables:** Comprehensive Python exploratory data analysis notebook highlighting high-risk customer profiles.

### [7. Analytics on Impact of Car Features](./Analyzing%20the%20Impact%20of%20Car%20Features%20on%20Price%20and%20Profitability)

* **Core Skills:** Exploratory Data Analysis (EDA), Regression Modeling, Correlation Matrices.
* **Key Deliverables:** Predictive regression models and identification of high-margin vehicle segments.

### [8. ABC Call Volume Trend Analytics](./Call%20Volume%20Trend%20Analytics)

* **Core Skills:** Time-Series Analysis, Data Manipulation, Trend Forecasting.
* **Key Deliverables:** Strategic recommendations for staffing allocation based on volume predictions.
